# Telegram-бот и сервер заказов PCBUILD

## Как это устроено

```
Сайт (форма заказа) ──POST /api/orders──▶ server.js ──▶ Telegram: карточка заказа сборщикам (кнопки)
                                              ▲                         │
Клиент ◀── уведомления о статусах ── Бот ◀────┴── сборщик нажимает кнопки / отвечает в поддержке
```

Всё работает в **одном боте** и **одном процессе** (`server.js`): он принимает заказы с сайта, общается с Telegram и сам раздаёт файлы сайта. Библиотеки не нужны, `npm install` делать не надо.

**Нужен ли сервер?** Да, программа должна быть запущена, пока бот работает. Но для учебного проекта хватит вашего компьютера: бот сам опрашивает Telegram, поэтому домен и HTTPS не нужны. Для работы 24/7 нужен хостинг с Node.js (см. «Публикация»).

## Что понадобится

- Node.js версии 18 или новее (nodejs.org, версия LTS). Проверка: в терминале `node -v`
- Аккаунт Telegram

## Шаг 1. Создать бота

1. В Telegram откройте **@BotFather** и отправьте `/newbot`.
2. Введите название (любое) и логин (должен заканчиваться на `bot`, например `pcbuild_shop_bot`).
3. BotFather выдаст **токен**. Это пароль от бота: никому не показывайте.

## Шаг 2. Узнать Telegram ID сборщиков

1. Каждый сборщик пишет боту **@userinfobot** и копирует число из строки `Id`.
2. **Каждый сборщик должен открыть вашего бота и нажать Start.** Без этого бот не сможет написать ему первым, и заказы не дойдут.

## Шаг 3. Разместить файлы

Папка `bot` уже лежит внутри папки проекта, рядом с `index.html`:

```
PCBUILD/
  index.html, css/, js/
  bot/
    server.js, package.json, env.example
```

Бот берёт `js/data.js` из проекта, поэтому цены и правила совместимости на сервере всегда совпадают с сайтом.

## Шаг 4. Настроить `.env`

1. В папке `bot` скопируйте `env.example` в файл с именем `.env`.
   - Если Windows не даёт создать файл, начинающийся с точки: в Блокноте «Сохранить как», имя файла `".env"` (в кавычках), тип «Все файлы».
2. Заполните:

```
BOT_TOKEN=токен_от_BotFather
BUILDER_IDS=111111111,222222222
PORT=3000
```

`BUILDER_IDS` — ID сборщиков через запятую. Все остальные пользователи автоматически считаются клиентами.

## Шаг 5. Запуск

```
cd путь\к\PCBUILD\bot
node server.js
```

Должно появиться `Бот @... запущен`. Сайт открывайте по адресу **http://localhost:3000**. Остановить: `Ctrl+C`.

## Шаг 6. Проверка

1. Откройте сайт, соберите ПК (обязательны процессор, плата, память, корпус, блок питания, накопитель), введите имя и телефон, нажмите «Оформить заказ».
2. Сборщикам придёт карточка заказа с кнопками.
3. На сайте нажмите «Следить за заказом в Telegram» → Start (лучше с другого аккаунта, чем у сборщика).
4. Сборщик нажимает «Принять в сборку»: клиенту приходит уведомление, а у остальных сборщиков карточка показывает «Ведёт: …».
5. Клиент пишет в бот любое сообщение: оно уходит сборщикам. Сборщик отвечает **реплаем (Reply)** на это сообщение.

## Роли и статусы

| Роль | Что может |
|---|---|
| Клиент | следить за заказом, смотреть «Мои заказы», писать в поддержку |
| Сборщик | принимать и отклонять заказы, менять статусы, отвечать клиентам |

Статусы: 🆕 Новый → 🛠 Сборка → 🔧 Собран → 🚚 Доставка → 📦 Выполнен (или ❌ Отклонён с причиной). Каждый шаг (кроме «Новый») клиент получает уведомлением.

- Заказ ведёт тот сборщик, кто нажал кнопку **первым**. Остальные видят, кто его взял, и менять статус не могут.
- При отклонении бот просит написать причину одним сообщением.
- Каждое сообщение клиента в поддержку подписано номером его заказа.

Команды сборщика: `/orders` (активные заказы), `/order 12` (открыть заказ №12), `/cancel`.

## Как открывать сайт

- Через бота: `http://localhost:3000` (сайт раздаёт сам сервер).
- Двойным кликом по `index.html`: тоже работает, заказы уходят на `http://localhost:3000`, пока бот запущен.
- Через Live Server или другой сервер на другом порту: в `js/builder.js` в строке `var API = ...` укажите `'http://localhost:3000'`.

## Публикация

- Нужен хостинг, где можно запускать Node.js (VPS, облачные сервисы вроде Render или Railway). Обычный статичный или PHP-хостинг не подойдёт.
- Процесс должен работать постоянно (например, через `pm2`). Файл `db.json` должен лежать на постоянном диске, иначе заказы пропадут при перезапуске.
- Для защиты проекта достаточно запустить на своём компьютере. Показать с телефона можно по адресу `http://IP_компьютера:3000` в одной Wi-Fi сети.

## Безопасность и ограничения

- Токен хранится только в `.env`. Не отправляйте его другим и не выкладывайте на GitHub. Если токен утёк, получите новый у @BotFather (`/revoke`).
- Цена и совместимость сборки **заново проверяются на сервере**: подделать заказ через консоль браузера нельзя.
- Не больше 5 принятых заказов в час с одного адреса.
- Папка `bot` с `.env` и `db.json` с сайта недоступна.
- Заказы хранятся в `db.json`. Для учебного проекта этого достаточно, для большого потока нужна настоящая база данных.
- Клиент без Telegram уведомлений не получит. Сборщик видит его телефон в карточке заказа и может позвонить.
- В поддержке поддерживается только текст (фото и файлы бот не пересылает).

## Частые проблемы

| Сообщение / симптом | Что делать |
|---|---|
| `Заполните BOT_TOKEN и BUILDER_IDS` | Файл `.env` лежит не в папке `bot` или не заполнен |
| `Не удалось подключиться к Telegram` | Неверный токен или нет доступа к Telegram из вашей сети |
| Сборщик не получает заказы | Он не нажал Start у бота или ID указан неверно |
| На сайте «Сервер заказов недоступен» | Не запущен `node server.js` или сайт открыт через сервер на другом порту (см. «Как открывать сайт») |
| `EADDRINUSE` | Порт занят: смените `PORT` в `.env` |
